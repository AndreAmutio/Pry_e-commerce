# ARCANA – E-commerce

**Alumna:** Amutio Andrea Sabrina  
**Asignatura:** Aplicaciones Web 1

## Descripción del proyecto

ARCANA es un proyecto de comercio electrónico desarrollado como trabajo práctico integrador. Está orientado a la presentación y comercialización de productos relacionados con la naturaleza, la alquimia y el universo astral.

El sitio permite recorrer las distintas secciones de la tienda, visualizar productos y utilizar un carrito de compras con funcionalidades implementadas mediante JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- Bootstrap Icons
- Google Fonts
- LocalStorage y SessionStorage
- Git y GitHub
- Vercel

## Funcionalidades principales

- Navegación entre las distintas páginas.
- Visualización dinámica de productos desde un archivo JSON.
- Secciones de productos Alquimia y Astral.
- Controles para modificar cantidades.
- Carrito de compras con almacenamiento local.
- Cálculo de subtotales y total de compra.
- Eliminación individual de unidades y opción para vaciar el carrito.
- Inicio y cierre de sesión mediante SessionStorage.
- Barra de navegación fija.

## Organización del proyecto

El proyecto se encuentra organizado en carpetas para separar los archivos HTML, CSS, JavaScript, imágenes y datos de productos.
